# Zsírozás 1.0

The first stable release brings the traditional Hungarian fat-card game to
Sailfish OS.

## Highlights

- Play an individual game against one computer opponent.
- Play the traditional four-player partnership game with three computer
  players and opposite-seat teams.
- Configure every opponent independently as Easy, Normal, Hard, or Expert.
- Choose the Piatnik or Betyár Hungarian card design.
- Use animated card movement at an adjustable speed, or disable animations for
  immediate play.
- Tap the human player's won pile to inspect captured cards, with tens and aces
  highlighted in colour.
- Learn the rules from illustrated in-app examples.
- Use the complete interface in English or Hungarian, selected automatically
  from the Sailfish system language.
- Continue an unfinished round automatically after the application or device
  is restarted.

The application plays entirely offline. Its About-page GitHub button opens the
public source repository only when selected.
